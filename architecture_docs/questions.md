## Abertas

1. **Qual domínio?**
   Default assumido: `nathanguimaraes.com.br` ou `nathanhgo.dev`, decidido no Registro.br, com as
   demos em `/demos` ou `demos.<dominio>`.
2. **Existe LinkedIn para linkar?**
   Default assumido: não incluir. O contato fica em e-mail e GitHub até existir perfil que o Nathan
   queira publicar.
3. **Entra foto pessoal?**
   Default assumido: não. A página sustenta a credibilidade pelo trabalho, não por retrato. Se entrar
   depois, tem que ser foto real, com boa luz, não de banco de imagens.
4. **O trabalho atual (estágio) pode ser citado?**
   Default assumido: citado de forma genérica ("estágio em desenvolvimento, com automação de coleta de
   dados e um portal de vagas"), sem nomear a empresa nem descrever o produto por dentro.
5. **Idioma: só português?**
   Default assumido: só português por enquanto. Se surgir busca por vaga fora do país, aí sim entra
   versão em inglês — e não antes.
6. **Quais projetos entram na lista?**
   Default assumido: só os com código público e descrição verificável. Trabalho acadêmico em grupo
   entra marcado como tal.
