# 90 — Commits (carregado sob demanda)

Formato: `tipo(escopo): descrição no imperativo em inglês`

Tipos: `feat`, `fix`, `docs`, `style`, `refactor`, `chore`. Escopos: `site`, `styles`, `projects`,
`demos`, `docs`, `deploy`.

- Um commit por mudança lógica; nunca misturar texto de projeto com ajuste de CSS.
- Exemplos:
  - `feat(projects): add vagas agent to the list`
  - `style(styles): raise body text to 17px`
  - `docs(visual): forbid fake metrics in copy`
  - `chore(deploy): document cloudflare pages setup`
- Nunca commitar segredo, telefone pessoal, endereço residencial ou dado de cliente.
