01 · sobre

O que eu faço

Curso o último ano de Análise e Desenvolvimento de Sistemas no IFSP, em Jacareí, e trabalho como estagiário de desenvolvimento — lido com automação de coleta de dados e manutenção de um portal de vagas. Fora do estágio construo as minhas próprias ferramentas: um editor de imagens por nós, um site de jogos de tabuleiro para jogar com amigos por link e um aplicativo de fichas de RPG.

Me interessa software que decide, não só software que executa: visão computacional aplicada a imagens aéreas, automação de processo repetitivo e processamento digital de imagens. Por isso mesmo prefiro entender o problema inteiro antes de escolher a ferramenta — já escrevi backend em Go e Python, frontend em React e TypeScript, aplicativo em Flutter e um benchmark só para medir onde cada modelo de concorrência ganha.

02 · projetos

O que já construí

  • FotoFácil — editor de imagens por nós

    Processamento de imagens em lote a partir de um fluxo montado visualmente: em vez de repetir a mesma edição arquivo por arquivo, a pessoa liga os blocos de processamento num quadro e aplica tudo em uma pasta inteira de uma vez. Trabalho apresentado no WORCAP, congresso do INPE.

    electron · react · typescript · go

    Código no GitHub

  • Fortuna — jogos de mesa para jogar por link

    Versões digitais de jogos de mesa clássicos (xadrez, Coup, batalha naval) em salas compartilháveis por link, sem cadastro e sem login: quem recebe o endereço entra e joga. O projeto existe porque reunir o grupo presencialmente é a parte difícil.

    next.js · react · python

    Código no GitHub

  • Ficha Digital RPG

    Aplicativo para fichas, sessões e inventário de um sistema de RPG próprio, baseado em D&D 5e. O mestre e os jogadores enxergam a mesma ficha atualizada em tempo real durante a sessão, o que elimina a papelada na mesa.

    flutter · dart · supabase

    Código no GitHub

  • Benchmark de processamento de imagens

    Comparação medida entre modelos de concorrência no processamento de imagens em lote: threads e processos em Python contra goroutines em Go, com o efeito do GIL aparecendo nos números. Feito para provar a escolha de arquitetura em vez de repetir o senso comum.

    python · go · opencv

    Código no GitHub

  • Semantic Skill Matcher

    Prova de conceito para o problema de vocabulário em recrutamento: quem escreve "programo em py" precisa ser encontrado pela vaga de "desenvolvedor Python". O projeto troca a busca por palavra-chave por casamento semântico entre currículo e vaga.

    prova de conceito

    Código no GitHub

  • Vagas — pipeline diário de candidaturas

    Rotina que roda todo dia: coleta vagas de estágio e júnior, filtra por perfil e localização, monta o resumo do dia, gera um currículo adaptado para cada vaga e registra as candidaturas em planilha. A coleta e o filtro são em Python puro, sem custo de modelo de linguagem.

    python · automação · cron

    Projeto pessoal, sem repositório público

  • CriptoLab Web (trabalho em grupo, faculdade)

    Sistema web com One Time Pad, Cifra de César, Vigenère e Cifra de Hill implementados do zero — sem nenhuma biblioteca de criptografia — mais um módulo de criptoanálise com força bruta sobre a César e demonstração do ataque por reutilização de chave em OTP.

    javascript · html · css

    Código no GitHub

03 · demonstrações

Páginas para comércio de bairro

Faço páginas de uma tela para comércio local com o que resolve o dia a dia de quem atende no balcão: o negócio aparece para quem procura pelo bairro, preços e horário ficam escritos sem ninguém precisar perguntar, e o contato cai direto no WhatsApp com a mensagem já escrita.

Nenhuma delas é o site oficial de um negócio: são propostas feitas antes de qualquer contratação, e saem do ar quando o dono pede. A lista de demonstrações está em construção — o endereço entra aqui assim que o primeiro lote de páginas estiver publicado.
